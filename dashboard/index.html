✏️ System Prompt
💡 نصائح كتابة Prompt مزيان
🎯 الأساسيات:
• حدد شخصية AI بوضوح
• اكتب لغة التواصل (دارجة/فصحى/إنجليزية)
• حدد عدد الجمل (جملتين = أحسن)
✅ ما يقولو:
• طرق الدفع المتاحة
• أسلوب الترحيب
• كيفاش يعرض المنتجات
❌ ما لا يقولو:
• لا يقول أنه AI أو بوت
• لا يكتب روابط
• لا يقول "آسف" أو "ما نقدرش"
⚡ المتغيرات التلقائية:
• [PRODUCTS] = قائمة السلع المتاحة
• [EXAMPLES] = أمثلة المحادثات
• [INSTRUCTION] = التعليمات الديناميكية
